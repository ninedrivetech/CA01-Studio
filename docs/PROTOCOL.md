# 知了1号通信协议

[返回首页](../README.md) · [使用指南](USER_GUIDE.md)

本文说明 CICADA-1 工作台使用的 UART 协议与发送约束。下文命令、回传和报文字节均使用十六进制；参数范围、字节数和时间使用十进制。

## 串口与接线

串口采用 **8 数据位、无校验、1 停止位（8N1），无流控**。主机 TX 接模块 RX，主机 RX 接模块 TX，双方共地，供电与 UART 电平按模块要求配置。

| BAUD0 | BAUD1 | 波特率 |
| --- | --- | --- |
| 低 | 高 | 9600 |
| 高 | 低 | 57600 |
| 高 | 高 | 115200 |
| 低 | 低 | 460800 |

模块在初始化时读取 BAUD 引脚。工作台的波特率选项只配置主机串口；两端必须一致。

## 帧结构

```text
FD  LEN_H  LEN_L  CMD  [DATA ...]
```

| 字段 | 长度 | 含义 |
| --- | --- | --- |
| `FD` | 1 字节 | 帧头 |
| `LEN_H LEN_L` | 2 字节 | 大端数据区长度，包含 CMD 和 DATA，不包含前三字节 |
| `CMD` | 1 字节 | 命令 |
| `DATA` | 可变 | 命令参数；无参数时省略 |

总帧长为 `LEN + 3`，无校验和。文本命令的 DATA 由一个编码标识和编码后的文本组成，因此 `LEN = 文本字节数 + 2`。

同帧字节间隔不超过 30 ms，帧间隔大于 30 ms。工作台普通命令发送后保留至少 35 ms 间隔，保存参数后至少 150 ms，休眠命令后至少 75 ms；下一步操作仍需等待相应回传。

## 命令

| CMD | 功能 | DATA | 工作台等待的回传 |
| --- | --- | --- | --- |
| `01` | 合成并播报 | 编码标识 + 文本 | `41` 接收确认，随后 `4F` 完成 |
| `02` | 停止 | 无 | `41` |
| `03` | 暂停 | 无 | `41` |
| `04` | 继续 | 无 | `41` |
| `05` | 读取语音参数 | 无 | `5F` + 17 字节 |
| `06` | 保存语音参数 | `01` + ASCII 控制标记（按 GBK 编码） | `4F` |
| `0A` | 保存特殊延时 | 三个大端 16 位无符号整数，共 6 字节 | `4F` |
| `0B` | 读取特殊延时 | 无 | `5E` + 12 字节 |
| `21` | 查询忙闲状态 | 无 | `4E` 或 `4F` |
| `22` | 无回传休眠 | 无 | 不等待回传 |
| `58` | 读取版本 | 无 | 原始字节响应 |
| `88` | 有回传休眠 | 无 | `4B` |
| `FF` | 唤醒 | 无 | `4A` |

保存声音参数前先停止播报。保存成功后，工作台会读取参数以更新显示。`22` 只表示主机已发送休眠命令，界面显示“休眠待确认”；有回传休眠由 `4B` 确认。

### 报文示例

```text
查询状态              FD 00 01 21
停止播报              FD 00 01 02
UTF-8 播报“你好”      FD 00 08 01 05 E4 BD A0 E5 A5 BD
保存音量 [v5]         FD 00 06 06 01 5B 76 35 5D
保存延时 0/0/50 ms    FD 00 07 0A 00 00 00 00 00 32
唤醒                  FD 00 01 FF
```

## 编码与分段

| 标识 | 编码 | 每段文本上限 |
| --- | --- | --- |
| `00` | GB2312 | 400 字节 |
| `01` | GBK | 400 字节 |
| `03` | UTF-16LE，无 BOM | 400 字节 |
| `04` | UTF-16BE，无 BOM | 400 字节 |
| `05` | UTF-8 | 400 字节 |

400 字节是工作台统一采用的兼容性限制，不包含帧头、长度、命令及编码标识。工作台不提供 BIG5，不允许无法由所选编码表示的字符，也不允许补充平面字符（如大多数表情）。

长文本按编码后的字节数自动分段，优先选择句末；完整字符、方括号控制标记和 `sound` 提示音名称不会被切开。单个标记或名称超出容量时会提示错误。工作台在当前段收到 `41` 确认及 `4F` 完成后发送下一段；`41` 本身不表示播报结束。停止或断开连接会清除剩余队列。

## 回传解析

回传不使用发送帧的 `FD + LEN` 结构。

| 回传 | 含义 |
| --- | --- |
| `41` | 命令接收成功 |
| `45` | 命令接收失败 |
| `4A` | 初始化或唤醒完成 |
| `4B` | 已进入休眠 |
| `4E` | 播放中 |
| `4F` | 空闲、播放完成或参数保存完成，结合当前命令判断 |
| `5F` | 后续固定 17 字节语音参数，总长 18 字节 |
| `5E` | 后续固定 12 字节特殊参数，总长 13 字节 |

接收方需缓存不完整回传，并处理一次读取中包含多个回传的情况。`5F` 和 `5E` 数据区内的字节不能再次解释为独立状态码。

### 语音参数

以下偏移从 `5F` 后第一个数据字节开始，以 0 为起点。工作台保留全部 17 字节，仅提取下表字段；未列出的字段不在本文中定义。

| 数据偏移 | 参数 |
| --- | --- |
| 2 | 语速 `s` |
| 3 | 音量 `v` |
| 4 | 语调 `t` |
| 5 | 发音人 `m` |
| 6–13 | 读法与识别选项，依次为 `x`、`f`、`n`、`y`、`b`、`z`、`i`、`r` |

### 特殊延时

`0A` 的三个数值和 `5E` 数据区的前三个数值均为大端 16 位无符号整数，单位为 ms。`5E` 后六字节为预留数据。

| 数据偏移 | 用途 | 范围 | 型号文档默认值 |
| --- | --- | --- | --- |
| 0–1 | 上电 POP 延时 | 0–200 | 0 |
| 2–3 | 句首丢音延时 | 0–250 | 0 |
| 4–5 | 句尾 POP 延时 | 0–300 | 50 |

### 版本响应与超时

版本命令 `58` 的响应长度与终止符没有在共用 UART 文档中定义。工作台发送后采集 2 秒内收到的原始字节，然后释放串口；该窗口不保证覆盖任意长度的响应。继续操作需重新连接。

普通请求的响应超时为 15 秒。超时或通信错误会关闭会话；工作台不会自动重发可能已被设备执行的命令。重新连接后应读取参数、查询状态，再决定后续操作。

## 控制标记与声音

标记写在方括号内，可作为播报文本的一部分，也可由 `06` 保存。标记设置全局生效并掉电保存。

| 标记 | 用途 | 示例或范围 |
| --- | --- | --- |
| `[m*]` | 发音人 | `[m3]` |
| `[v*]` | 音量 | 0–10 |
| `[s*]` | 语速 | 1–30 |
| `[t*]` | 语调 | 1–10 |
| `[p*]` | 静音时长 | 0–32000 ms |
| `[x1]` | 开启提示音识别 | `[x1]sound901` |
| `[d]` | 恢复默认设置，保留发音人 | 全部恢复使用 `[d][m3]` |

| 发音人编号（十进制） | 名称 |
| --- | --- |
| 3 | 晓玲 |
| 51 | 尹小坚 |
| 52 | 易小强 |
| 53 | 田蓓蓓 |
| 54 | 唐老鸭 |
| 55 | 小燕子 |
| 56 | 贝童 |
| 57 | 晓可 |

提示音示例：`[x1]sound901[p100]sound901` 表示两次短蜂鸣，中间静音 100 ms。提示音名称与相邻英文字母或数字之间使用空格或标点分隔。其他中文读法标记参见厂商标记表。

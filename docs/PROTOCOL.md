# 知了1号通信依据

核对日期：2026-09-11。命令格式参考共用UART文档，参数参考VTX316型号页；发送容量以COM9实测兼容性为约束。

- https://www.doc.voicetx.com/zh/home/VTX316
- https://public.voicetx.com/zh/home/uart
- https://public.voicetx.com/zh/home/mark_cn
- https://public.voicetx.com/zh/home/encoding

帧：FD + 两字节大端数据区长度 + 命令 + 可选编码 + 数据，无校验和。字节间隔不超过 30ms，帧间隔超过 30ms。设置后等待 4F 或至少 150ms。长文本必须等上一段 4F 播放完成才能发送下一段。

VTX316型号页标称：GB2312=00、GBK=01、UTF-16LE=03、UTF-16BE=04文本上限4000字节；UTF-8=05上限2000字节。COM9实测五种编码400和500字节返回41、512字节返回45；UTF-8/GBK的600字节及以上测试帧也返回45。尚未测定500到512间的精确上限。应用前端与Rust统一限制为400字节，保留余量，并优先按句末分段。证据：com9-capacity-report.json、com9-boundary-report.json。通用UART文档也提示存在400字节容量的芯片变体，不能仅凭型号页假定当前设备容量。

不提供BIG5。八个发音人：3晓玲、51尹小坚、52易小强、53田蓓蓓、54唐老鸭、55小燕子、56贝童、57晓可。UART示例误把m3标成小燕子，以型号页和标记表为准。

串口 8N1，无流控。BAUD0/BAUD1：0/1=9600，1/0=57600，1/1=115200，0/0=460800。软件选择的是主机波特率，不修改硬件引脚。

命令：01合成、02停止、03暂停、04继续、05读取参数、06保存参数、0A保存特殊参数、0B读取特殊参数、21状态、22无回传睡眠、88有回传睡眠、FF唤醒、58版本。

回传：41接收成功、45失败、4A初始化/唤醒、4B睡眠、4E播放中、4F空闲/播放完成/设置完成。5F后固定17字节参数（含两字节编码）；5E后固定12字节特殊参数（末6字节预留）。多字节回传内部可含状态字节，必须按长度解析。58版本的长度/终止符在共用文档中未定义，保留原始响应，不臆造固定长度。

特殊延时按型号默认 0/0/50ms；范围分别0–200、0–250、0–300ms。与通用页200/250/50默认值不同。标记设置全局生效并掉电保存，滑条改变不得自动发送。[d]不重置发音人；[d][m3]恢复全部默认。语速1–30、音量0–10、语调1–10、静音[p*]0–32000ms。

实现与验证进度见 README.md。没有实机测试时不得把模拟器结果称为硬件验证。

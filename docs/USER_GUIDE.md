# 知了1号使用指南

英文代号：CICADA-1。首页左侧是文本编辑与提示音，右侧是声音参数，下方是通信记录与发送预览。顶部状态栏显示连接状态、语言切换图标、设置齿轮和日夜切换；底部状态栏保留分段信息。

## 下载通信日志

点击通信记录工具栏的「导出日志」，打开与当前琥珀、森林、夜间或高对比主题一致的下载弹窗。弹窗显示文件名、记录数、UTF-8编码和文件字节数；点击「下载文件」保存 `.log` 文件，点击「取消」、关闭按钮或 Escape 返回工作台。导出内容固定为打开弹窗时的筛选结果，后台新日志不会改变这份快照；没有匹配记录时下载按钮禁用。

## 连接与播报

1. 将 USB 转 UART 的 TX 接模块 RX、RX 接模块 TX，连接 GND。使用适合模块的供电和 UART 电平，接好扬声器。
2. 启动桌面程序，在首页顶部连接栏选择真实串口，默认COM9。串口选择器显示系统设备名称，如USB-SERIAL CH340 (COM9)，列表每3秒刷新。可搜索设备名/COM口，使用方向键与Enter选择；也可以在列表底部输入COM号后点「使用端口」。连接只使用COM9这样的原始端口号。
3. 选择与模块引脚一致的波特率，默认悬空 BAUD0/BAUD1 为115200。连接后自动查询忙闲状态并读取语音参数与特殊延时。
4. 在首页「文本与提示音」输入文字，选择编码，检查字节数与分段数，然后点击「开始播报」。原始帧预览对应当前文本第一段。
5. 点击暂停/继续控制当前播报；点击停止取消剩余分段。长文本播放期间不应再手动发新文本，以免芯片中断上一帧。

浏览器预览请选择模拟设备。模拟器只演示回传和界面，不调用电脑语音引擎，不代表模块的真实音色。

模块休眠后若串口已经断开，请使用「唤醒并连接」：先发送唤醒命令并等待4A，再查询状态和参数。普通连接适用于已上电且未休眠的模块。

## 设置声音

在首页右侧「语音参数」选择八种发音人之一，设置音量（0–10）、语速（1–30）、语调（1–10）及读法。点击保存后等待设备回传，再读取设备参数。显示的滑条只是编辑值，改变滑条不会立即写入模块。保存过程不要断电。

参数永久保存到模块。文本中的 `[v8]`、`[s7]`、`[m55]` 等标记也会全局生效。需要确认文本播放后的实际参数时点击「重新读取」。恢复默认会发送 `[d][m3]`，其中 `[d]` 不单独恢复发音人。

## 文本与提示音

所有编码每段文本不超过400字节，首页实时显示分段数。COM9实测较长单帧会返回45，因此不采用型号页的2000/4000字节理论容量。分段优先选择句末，并保护完整字符、方括号标记和提示音名称；收到上一段完成回传后自动续播。不支持的表情等字符会报错，避免静默替换。GB2312限制在实际已分配字符范围，不将完整GBK误当GB2312。

文本导入接受UTF-8 `.txt`，最大1MB。草稿保存在本机。尽量用逗号和句号断句，连续无标点超过60字符可能影响芯片韵律判断。

「提示音」包含型号文档列出的13种内置提示音。点击后插入工作台，检查文字再播放。`[x1]sound901` 开启提示音识别并播放短蜂鸣；`sound901[p100]sound901` 中间停顿100ms。提示音名称与相邻英文字母/数字用空格或标点分开。

## 设备配置

点击顶部状态栏的设置齿轮，在弹出的子窗口中操作「设备设置」。该窗口与主界面共用当前串口会话，打开或关闭不会停止正在播放的队列。关闭按钮、「完成」或Esc返回首页，键盘焦点回到设置按钮。关闭保留未保存的延时编辑值，只有点击「保存延时」才写入设备。

波特率只配置主机串口，芯片波特率由BAUD引脚在初始化时确定。

| BAUD0 | BAUD1 | 波特率 |
| --- | --- | --- |
| 低 | 高 | 9600 |
| 高 | 低 | 57600 |
| 高 | 高 | 115200 |
| 低 | 低 | 460800 |

特殊延时默认0/0/50ms，分别对应上电POP、句首丢音、句尾POP；最大200/250/300ms。仅在功放确实需要调节时修改，保存后会读回确认。

休眠功能要求适用的POPEN高电平硬件方案。唤醒成功以4A回传确认；无法唤醒时检查接线与供电，不要连续盲发文本。

“进入休眠”使用88并等待4B确认；“无回传睡眠”使用22，仅确认主机已发送，显示“休眠待确认”，需要唤醒后继续操作。

“读取版本并断开”发送58，保留2秒采集窗口内的全部原始响应。官方未定义版本响应长度和终止标志，软件不猜测版本字段，也不承诺窗口已收齐全部字节。查询后释放串口，重新连接可继续操作。

## 通信诊断

TX为发送、RX为接收，HEX显示原始字节；可按方向和内容筛选。暂停显示不停止接收，后台仍保留最近500条记录。导出的是当前筛选的记录，清空只影响上位机日志。

41表示命令接收成功，4F表示空闲、播放完成或参数保存完成，45表示接收失败。语音参数回传以5F开头，特殊参数以5E开头；其内部字节不可单独解释成状态码。

若响应超时，软件关闭当前会话，不自动重发可能已执行的命令。重新连接后读取参数并检查设备实际状态。报文中的文本内容会出现在日志中，分享日志前请自行检查需要保留的内容。

## 外观

顶部语言图标可直接在中文和English之间切换，设置窗口底部也有「界面语言 / Interface language」选项。语言即时生效、自动保存，重启后沿用。界面语言不会翻译播报文本，也不会修改模块声音参数或更换串口。英文界面不代表芯片新增英文单词合成能力。

在「设置」子窗口的「外观设置」选择主题与动态效果，选择即时生效并自动保存。界面采用统一布局，不再提供布局密度选项。原版本主题偏好自动沿用。顶部按钮切换初鸣/夜鸣。

| 主题 | 英文名称 | 配色与用途 |
| --- | --- | --- |
| 初鸣 | First Song | 晨光暖白，日间专注 |
| 林鸣 | Grove | 叶影浅绿，柔和自然 |
| 夜鸣 | Nocturne | 月下深青，夜间工作 |
| 明翼 | Clearwing | 墨底亮金，高对比 |

默认1280×820窗口一屏展示主要操作。较窄窗口自动换行，设置子窗口内容可独立滚动，关闭操作始终可见。减少动态效果可跟随系统或手动开启。应用无需下载字体和在线资源。

# 知了1号使用指南

[返回首页](../README.md) · [通信协议](PROTOCOL.md)

CICADA-1 将串口连接、文本编辑、声音参数和通信记录放在同一工作台中。顶部状态栏提供连接、语言切换、设置和日夜主题切换；设置窗口包含设备与外观选项。

## 启动

桌面环境和源码启动步骤见 [README](../README.md)。在项目根目录执行 `npm ci`，然后执行 `npm run desktop`。桌面模式支持真实串口；通过 `npm run dev` 打开的浏览器界面只能使用模拟设备。模拟设备演示界面和协议回传，不输出声音。

## 接线与连接

1. 将 USB 转 UART 的 TX 接模块 RX、RX 接模块 TX，并连接 GND。按模块要求选择电源与 UART 电平，连接扬声器。
2. 在顶部连接栏选择实际串口。列表显示系统设备名称，可按设备名或端口搜索；也可以手动输入端口。方向键与 Enter 可完成选择。
3. 选择与模块 BAUD0/BAUD1 引脚一致的波特率，点击连接。连接后自动查询忙闲状态，并读取声音参数和特殊延时。

串口固定为 8N1、无流控。波特率由模块在初始化时读取 BAUD 引脚确定；软件只配置主机端。

| BAUD0 | BAUD1 | 波特率 |
| --- | --- | --- |
| 低 | 高 | 9600 |
| 高 | 低 | 57600 |
| 高 | 高 | 115200 |
| 低 | 低 | 460800 |

已休眠的模块请使用“唤醒并连接”，等待 `4A` 唤醒回传后再操作。普通连接适用于已上电且未休眠的模块。

## 输入文本与播报

在“文本与提示音”中输入文字，选择 GB2312、GBK、UTF-16LE、UTF-16BE 或 UTF-8 编码。工作台显示编码后的字节数、分段数及每段报文预览。点击“开始播报”后可暂停、继续或停止；停止会取消剩余分段。

每段最多 **400 字节**。长文本优先按句末分段，并保护完整字符、控制标记和提示音名称；收到上一段完成回传后自动续播。播放期间不要从其他上位机发送文本，以免中断当前播报。

- 文本导入接受 UTF-8 编码的 `.txt` 文件，最大 1 MB；导入失败时保留当前草稿。
- 草稿保存在本机，下次打开可以继续编辑。
- 不支持的字符会提示错误，不能发送表情等补充平面字符。
- 使用逗号和句号分隔句子；连续无标点超过 60 字符可能影响芯片韵律。
- 模块支持中文字库及英文字母，不提供英文单词语音合成。

### 提示音与控制标记

“提示音”提供 13 种内置声音，点击即可插入编辑区。提示音名称与相邻英文字母或数字之间使用空格或标点分隔。

```text
[x1]sound901
[x1]sound901[p100]sound901
[v8][s7][m55]欢迎使用知了一号。
```

第一行播放短蜂鸣；第二行播放两次短蜂鸣，中间停顿 100 ms；第三行设置音量、语速与发音人后播报文字。更多标记见[通信协议](PROTOCOL.md)。

## 设置声音

在“语音参数”中选择八种发音人之一，设置音量（0–10）、语速（1–30）、语调（1–10）及中文读法。滑条只是编辑值，点击保存才会写入模块；保存前先停止播报，保存过程中保持供电与连接。

保存后工作台读取设备参数以更新显示。文本中的 `[v8]`、`[s7]`、`[m55]` 等标记也会全局生效并掉电保存；需要确认当前值时点击“重新读取”。

恢复默认发送 `[d][m3]`。单独的 `[d]` 保留当前发音人，附加 `[m3]` 才恢复默认发音人晓玲。

## 设备设置

点击顶部齿轮打开设置窗口。设置窗口与首页共用串口会话，关闭窗口不会停止播放。关闭按钮、“完成”或 Esc 返回首页，Tab 与 Shift+Tab 可在窗口内切换焦点。

### 功放特殊延时

三个延时分别对应上电 POP、句首丢音、句尾 POP，单位为 ms。型号文档默认值为 0 / 0 / 50，最大值为 200 / 250 / 300。按功放实际需要调整，点击“保存延时”后写入并读回确认。关闭设置窗口会保留尚未保存的编辑值。

### 休眠与唤醒

休眠功能要求适用的 POPEN 高电平硬件方案。

- “进入休眠”发送 `88`，等待 `4B` 确认。
- “无回传睡眠”发送 `22`，仅确认主机已发送，显示“休眠待确认”。
- 唤醒成功由 `4A` 确认；模块与主机已断开时使用“唤醒并连接”。

### 读取版本

“读取版本并断开”发送 `58`，采集 2 秒内收到的原始响应，然后释放串口。厂商共用文档未定义版本响应长度和终止符，因此界面保留原始数据。读取后重新连接即可继续操作。

## 通信记录

TX 表示发送，RX 表示接收，HEX 展示原始字节。可按方向和内容筛选，展开日志区域以阅读更多记录。

暂停显示不会停止接收，后台仍保留最近 500 条记录。清空只影响工作台日志。点击“导出日志”后，在跟随当前主题的弹窗中编辑文件名、查看保存位置和内容预览。桌面端点击“下载文件”会直接将 UTF-8 `.log` 文件保存到系统“下载”目录，同名文件自动编号，不覆盖已有文件；完成后弹窗显示实际路径。保存失败会显示原因，可调整文件名或检查目录权限后重试。浏览器预览模式将文件交给浏览器下载。导出内容固定为打开弹窗时的筛选结果，没有匹配记录时无法下载，单次导出最大 8 MB。

常见回传：`41` 表示接收成功，`4F` 表示空闲、播报完成或参数保存完成，`45` 表示接收失败。`5F` 与 `5E` 分别引导语音参数和特殊参数数据，其内部字节不能单独解释成状态码。完整格式见[通信协议](PROTOCOL.md)。

## 语言与外观

顶部语言按钮或设置中的“界面语言”可切换中文和 English，偏好即时保存。界面语言不会翻译播报文本，也不会修改模块声音或串口设置。

| 主题 | 英文名称 | 配色 |
| --- | --- | --- |
| 初鸣 | First Song | 晨光暖白 |
| 林鸣 | Grove | 叶影浅绿 |
| 夜鸣 | Nocturne | 月下深青 |
| 明翼 | Clearwing | 墨底亮金，高对比 |

设置窗口可选择主题与动态效果，顶部日夜按钮切换初鸣和夜鸣。减少动态效果可跟随系统或手动开启。较窄窗口自动调整布局，内容较多时可滚动；应用运行无需下载字体和在线资源。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 找不到串口 | 检查 USB-UART 连接及驱动，按设备名搜索，或手动输入实际端口；关闭占用该端口的其他程序。 |
| 连接后无响应 | 检查供电、共地、TX/RX 接线和两端波特率；若模块休眠，使用“唤醒并连接”。 |
| 浏览器界面没有声音 | 浏览器使用模拟设备；真实播报需要桌面模式、模块及扬声器。 |
| 文本编码失败 | 移除不受支持的字符，或选择可表示文本的编码；补充平面字符不能发送。 |
| 返回 `45` | 检查报文格式、编码和文本容量，按每段最多 400 字节发送。 |
| 响应超时、连接关闭 | 重新连接并读取参数、查询状态后再继续；工作台不自动重发，以免重复执行命令。 |
| 读取版本后连接断开 | 此操作采集完原始响应后会释放串口，重新连接即可。 |

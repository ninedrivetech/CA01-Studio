# 知了1号 / CICADA-1 界面规范

产品代号CICADA-1与中文名一一对应；首页标题、原生窗口标题与设置窗口统一使用此代号。主题取自蝉鸣与蝉翼，使用中文短名加英文名称，同时保留配色用途说明。

顶部状态栏包含连接状态、语言切换图标、设置齿轮及日夜切换。设置入口不再占据底部。中文/English界面使用显式文案字典，保留底层状态机、串口号与用户文本；语言偏好持久化，窗口标题同步切换。

串口通过原生枚举返回name、description、manufacturer；Windows额外读取Ports设备类的友好名称，覆盖USB和非USB串口。缺少系统描述时显示端口类别。自定义选择器沿用主题变量，支持搜索、方向键/Enter/Esc、手动输入，打开时定位当前选中设备，最终只将原始name传给连接接口。名称自带(COMx)时不重复附加。

首页采用两栏：左侧扩大文本编辑区，保留全部13种提示音和控制标记；右侧集中声音参数，音量/语速/语调并排展示。底部保留通信记录与发送预览，最下方状态栏显示连接、分段信息与设置入口。

设备和外观从首页移入原生HTML dialog构成的模态子窗口（不是独立操作系统窗口），与首页共用串口会话及编辑状态。Tab/Shift+Tab在窗口内循环，Esc/关闭/完成返回首页，焦点恢复到入口。弹窗关闭不丢弃未保存的延时值，也不会取消播放；设备写入仍需明确点击保存。设备反馈在弹窗内显示，避免被遮罩遮挡。

主题沿用amber/forest/night/contrast存储键，分别对应初鸣/First Song、林鸣/Grove、夜鸣/Nocturne、明翼/Clearwing，旧偏好保持兼容。色板使用语义变量，并在主题卡上同时显示色样、文字与选中标记。

桌面优先考虑鼠标和键盘密度；小屏幕设置内容单列滚动。底部状态栏预留占位，关闭按钮和完成按钮保持可达。动效仅用于弹窗入场，并尊重系统和本机减少动态效果设置。
